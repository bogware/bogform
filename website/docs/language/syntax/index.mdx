# Syntax

The majority of the Bogform language documentation focuses on the practical
uses of the language and the specific constructs it uses. The pages in this
section offer a more abstract view of the Bogform language.

- [Configuration Syntax](../../language/syntax/configuration.mdx) describes the native
  grammar of the Bogform language.
- [JSON Configuration Syntax](../../language/syntax/json.mdx) documents
  how to represent Bogform language constructs in the pure JSON variant of the
  Bogform language. Bogform's JSON syntax is unfriendly to humans, but can
  be very useful when generating infrastructure as code with other systems that
  don't have a readily available HCL library.
- [Style Conventions](../../language/syntax/style.mdx) documents some commonly
  accepted formatting guidelines for Bogform code. These conventions can be
  enforced automatically with [`bogform fmt`](../../cli/commands/fmt.mdx).
