# Bogform vs. Alternatives

Bogform provides a flexible abstraction of resources and providers. This model
allows for representing everything from physical hardware, virtual machines, and
containers, to email and DNS providers. Because of this flexibility, Bogform
can be used to solve many different problems. This means there are a number of
existing tools that overlap with the capabilities of Bogform. We compare Bogform
to a number of these tools, but it should be noted that Bogform is not mutually
exclusive with other systems. It can be used to manage a single application, or the
entire datacenter.
