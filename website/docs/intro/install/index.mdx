# Installing Bogform

Bogform is a single executable, published on
[GitHub Releases](https://github.com/bogware/bogform/releases) and as a container image.

## Download a release

1. Download the archive for your operating system and CPU from the
   [releases page](https://github.com/bogware/bogform/releases). Archives are named
   `bogform_<VERSION>_<OS>_<ARCH>.tar.gz` or `.zip`. Each release also includes `.deb`, `.rpm`,
   and `.apk` packages.
2. Verify the download:

   ```shell
   sha256sum --ignore-missing -c bogform_<VERSION>_SHA256SUMS
   ```

3. Unpack the archive and put `bogform` somewhere on your `PATH`.
4. Confirm that it works:

   ```shell
   bogform version
   ```

## Verify a release signature

Releases are signed with [cosign](https://docs.sigstore.dev/cosign/system_config/installation/)
using GitHub's identity, so there is no long-lived signing key to trust. To verify the checksum file:

```shell
cosign verify-blob \
  --certificate bogform_<VERSION>_SHA256SUMS.pem \
  --signature bogform_<VERSION>_SHA256SUMS.sig \
  --certificate-oidc-issuer https://token.actions.githubusercontent.com \
  --certificate-identity-regexp '^https://github\.com/bogware/bogform/\.github/workflows/release\.yml@' \
  bogform_<VERSION>_SHA256SUMS
```

## Use the container image

```shell
docker run --rm -it -v "$PWD:/workspace" -w /workspace ghcr.io/bogware/bogform:latest init
```

The `-minimal` image tags contain only the `bogform` executable. Use the standard tags if your
configuration needs `git` or `ssh`, for example to download modules from a Git repository.

## Build from source

With the Go version named in `go.mod` installed:

```shell
git clone https://github.com/bogware/bogform.git
cd bogform
go build -o bogform ./cmd/bogform
```
