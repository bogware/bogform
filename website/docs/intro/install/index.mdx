# Installing Bogform

Bogform is a single executable, published on
[GitHub Releases](https://github.com/bogware/bogform/releases), through Homebrew, Scoop and
winget, and as a container image. Every method installs the same signed release.

## Install script

On Linux, macOS or the BSDs:

```shell
curl -fsSL https://raw.githubusercontent.com/bogware/bogform/main/scripts/install.sh | sh
```

On Windows, in PowerShell:

```powershell
irm https://raw.githubusercontent.com/bogware/bogform/main/scripts/install.ps1 | iex
```

The scripts install the latest stable release, check it against the release's checksums, and,
if [cosign](https://docs.sigstore.dev/cosign/system_config/installation/) is installed, check
the release's signature too. Set `BOGFORM_VERSION` to choose a version, or `BOGFORM_INSTALL_DIR`
to choose where it goes. Read the script before you run it:
[install.sh](https://github.com/bogware/bogform/blob/main/scripts/install.sh),
[install.ps1](https://github.com/bogware/bogform/blob/main/scripts/install.ps1).

## Package managers

| Platform | Command |
|---|---|
| macOS (Homebrew) | `brew install --cask bogware/tap/bogform` |
| Windows (Scoop) | `scoop bucket add bogware https://github.com/bogware/scoop-bucket` then `scoop install bogware/bogform` |
| Windows (winget) | `winget install Bogware.Bogform` |
| Debian, Ubuntu, Fedora, Alpine | Download the `.deb`, `.rpm` or `.apk` from the [releases page](https://github.com/bogware/bogform/releases) |

Package managers get stable releases only. Prereleases are on the releases page.

## Download a release

1. Download the archive for your operating system and CPU from the
   [releases page](https://github.com/bogware/bogform/releases). Archives are named
   `bogform_<VERSION>_<OS>_<ARCH>.tar.gz` or `.zip`. Each release also includes `.deb`, `.rpm`,
   and `.apk` packages.
2. Verify the download:

   ```shell
   sha256sum --ignore-missing -c bogform_<VERSION>_SHA256SUMS
   ```

3. Unpack the archive and put `bogform` somewhere on your `PATH`.
4. Confirm that it works:

   ```shell
   bogform version
   ```

## Verify a release signature

Releases are signed with [cosign](https://docs.sigstore.dev/cosign/system_config/installation/)
using GitHub's identity, so there is no long-lived signing key to trust. To verify the checksum file:

```shell
cosign verify-blob \
  --certificate bogform_<VERSION>_SHA256SUMS.pem \
  --signature bogform_<VERSION>_SHA256SUMS.sig \
  --certificate-oidc-issuer https://token.actions.githubusercontent.com \
  --certificate-identity-regexp '^https://github\.com/bogware/bogform/\.github/workflows/release\.yml@' \
  bogform_<VERSION>_SHA256SUMS
```

## Verify where a file was built

Each release file also has a [build attestation](https://docs.github.com/actions/security-for-github-actions/using-artifact-attestations),
which records the workflow and commit that built it, and an SPDX SBOM (`.sbom.json`) that lists
what's inside it. With the GitHub CLI:

```shell
gh attestation verify bogform_<VERSION>_linux_amd64.tar.gz --repo bogware/bogform
```

## Use the container image

```shell
docker run --rm -it -v "$PWD:/workspace" -w /workspace ghcr.io/bogware/bogform:latest init
```

The `-minimal` image tags contain only the `bogform` executable. Use the standard tags if your
configuration needs `git` or `ssh`, for example to download modules from a Git repository.

## Build from source

With the Go version named in `go.mod` installed:

```shell
git clone https://github.com/bogware/bogform.git
cd bogform
go build -o bogform ./cmd/bogform
```
