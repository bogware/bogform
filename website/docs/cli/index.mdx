# Bogform CLI Documentation

This is the documentation for Bogform CLI. It is relevant to anyone working
with Bogform's CLI-based workflows, whether on their own machine or in a pipeline.

Notably, this documentation does not cover the syntax and usage of the Bogform
language. For that, see the
[Bogform Language Documentation](../language/index.mdx).
