# Command: state rekey

The `bogform state rekey` command reads every workspace's state and writes it again, encrypted with the `state` block's method. Use it to finish rotating a passphrase or key.

## Usage

Usage: `bogform state rekey [options]`

```
$ bogform state rekey
default: re-encrypted (serial 4 → 6)
staging: re-encrypted (serial 2 → 4)

Earlier versions in the backend's history are still encrypted with the old key. If it was exposed, treat them as exposed too.
```

See [Rotating a passphrase](../../../language/state/encryption.mdx#rotating-a-passphrase) for the steps around it. In short: add the new key with the old one as a `fallback`, run `bogform state rekey`, then remove the fallback.

Rekeying doesn't change any resources, only the serial. Each workspace is locked while it's rewritten.

Options:

- `-workspace=NAME` - Rekey only this workspace. Defaults to every workspace.
- `-lock=false` - Don't hold the state lock. This is dangerous if others might run commands at the same time.
- `-lock-timeout=DURATION` - How long to keep trying to take the lock, such as `30s`.
