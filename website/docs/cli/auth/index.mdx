# CLI Authentication

Some services that Bogform can use, such as private module and provider registries, require an API
token.

The best way to handle CLI authentication is with the `login` and `logout` commands, which help
automate the process of getting an API token for your account on that service.

For details, see:

- [The `bogform login` command](../commands/login.mdx)
- [The `bogform logout` command](../commands/logout.mdx)
